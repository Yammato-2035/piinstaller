# FAQ — Install Linux from the rescue stick (EN)

## Which Linux systems are planned?
Linux Mint (currently supported), Ubuntu Server LTS, Ubuntu Server, and Debian install. Debian Live is the stick runtime, not an install target.

## When may partitioning/install run?
Only after **explicit approval** or **successful backup+verify** of affected media — plus confirmation in the assistant.

## What happens for ASUS ROG now?
Plan: Linux Mint on the **second NVMe** from the live stick session (no reseating). The Windows NVMe stays protected. Orchestration is driven from the development laptop.

## Are telemetry and diagnostics servers public?
No. Servers stay in **private** GitHub repositories; the public repo only has contracts, mocks, and docs.

## Is BIOS flashed automatically?
No. Only a guided diagnosis/compare session — flashing is operator-only.
