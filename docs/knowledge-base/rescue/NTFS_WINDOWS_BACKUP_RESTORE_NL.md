# NTFS/Windows Terugup & Herstel (Wissen)

**Kurz:** rooddingsstick erkennt Windows/NTFS alleen-lezen; Image-Terugup/Herstel sind separate gated Läufe (F.2–F.4).

## Regeln

- Kein Passwort-/BitLocker-Bypass
- Externes Terugup-Ziel Pflicht
- Systemplatte Linux (`nvme1n1` im F.1-Host) niemals als Ziel
