# Déploiement Runner Release Readiness Matrix (lecture seule)

## Goal

Central readiness matrix for the runner/Déploiement-write chain with status, risks, and gaps.

## Status model

- `bloqué`: blocking gaps present
- `review_requirouge`: Non blockers, but review gaps remain
- `ready_for_lab`: lab-ready only, Nont production release
